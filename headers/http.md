# HTTP

É uma dos protocolos de transferencia de dados que é uma das bases da World Wide Web. Um "flow" entre requisições e respostas onde envolve um cliente e um servidor.

## O que é um método HTTP???

É algumas vezes, conhecido por verbos HTTP, que indica uma ação que aquela requisição está pedindo/enviando. Os mais comuns são o GET e POST, GET é um pedido para "pegar" as informações do servidor e o POST é onde o cliente/usuário envia informações para o servidor.

## O que está por dentro de uma requisição do HTTP:

Uma resposta HTTP é o que o clientes web, recebem de uma resposta do servidor. Um HTTP normal sempre vai conter:

- Um http status code;
- cabeçalho http de resposta;
- um body opcional de http;
